# Mini City 3b: Coins, Stunt Park, Missions — Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** Give the mini city coins to grab, Murad's Stunt Park with cheered jumps and mid-air flips, short pizza-shop missions, and hidden "Murad" surprises.

**Architecture:**
- **Pure modules** (no three, no DOM, `node:test`) hold all rules and map data: progress save, coin spots and pickup, the stunt tracker, stunt park geometry, missions.
- **vehiclePhysics** gains an `airControl` option and a `wheelsDown()` read.
- **Three.js side:**
  - `cityWorld` builds the stunt park and signs;
  - `cityCoins.js` draws and collects coins;
  - `cityMissions.js` runs the mission UI and objects;
  - `city.js` wires them into the frame loop and HUD.

**Tech Stack:** Three.js 0.170 and cannon-es 0.20 (import map), ES modules, no build step, `node --test`.

**Spec:** `docs/superpowers/specs/2026-10-16-city-fun-design.md`

## Global Constraints

- Pure modules must not import three or touch the DOM.
- Kid-safe: nothing is ever taken away. A timeout says only "So close! Try again?".
- Missions start only when he enters the pizza ring and taps **Let's go! ▶**.
- `HERO_NAME = 'Murad'` lives in `js/cityMap.js` and is used for every name surprise. No on-screen text announces it.
- Save key `brickRacers.progress.v1` = `{ coins, missionsDone }`. Bad data → `{ coins: 0, missionsDone: 0 }`.
- Coins: small = 1, big = 5. Pickup within 1.2 m on foot, 2 m in a car, height difference < 3 m. Respawn after 90 s.
- Stunts (on landing upright, up·y > 0.7, ≥ 2 wheels down, after airborne = 0 wheels for > 0.15 s):

  | Stunt | Condition | Reward |
  |---|---|---|
  | BIG AIR | air time ≥ 0.7 s | 5 |
  | HUGE AIR | air time ≥ 1.4 s, replaces BIG AIR | 10 |
  | FLIP | ≥ 300° pitch | 20 |
  | BARREL ROLL | ≥ 300° roll | 20 |
  | 360 SPIN | ≥ 330° yaw | 15 |
  | RING OF FIRE | through the hoop while airborne, awarded at once | 10 |

  - Not upright within 1 s of touching down → "Oops! 🙃", 0 coins.
- Missions:

  | Kind | Timer | Reward |
  |---|---|---|
  | pizza | 25 s + straight-line metres / 5 | 30 |
  | puppy | none | 40 |
  | coin trail (10 blue coins) | 60 s | 30 |
  | stunt | none | 40 |

  - Ring ready again 5 s after a mission ends.
  - Rotation: pizza → puppy → coinTrail → stunt.
- Air control (city only):
  - pad and keys turn the airborne car: ◀/▶ spin, GO nose down, STOP nose up;
  - about 0.9 s per full turn;
  - a landing helper levels the car when no air button is held and it is within 60° of upright.
- New static bodies use `SURFACE_MATERIAL` and `aabbNeedsUpdate = true`.
- Coins are drawn with `InstancedMesh`.
- Frame time stays < 8 ms (update + render) at 1024×768.
- Touch targets ≥ 60 px. Mission titles and "Mission complete!" are spoken with `speak()` from `audio.js`.

## Review Focus

1. **Leaving the city mid-mission** (Home, My cars, race gate, pause → Home): no stray banner, beam, pizza box, timer tick or speech carries into the next screen. The next visit offers the same mission again.
2. **A mission card opened while driving:** the city is frozen while the card is up, and held pad buttons are released, so the car doesn't roll on under the card.
3. **Air control vs ground driving and races:** air torque never applies with a wheel down, and races (no `airControl`) behave exactly as before.
4. **Coins collected in a car vs on foot at garage heights:** a coin on the 1st floor isn't grabbed from the ground floor below (height rule), and big coins mid-air over the kicker are reachable by a car in flight.
5. **The stunt tracker across get-out / get-in and flips via "Flip me!":** a Flip me! reset or getting out mid-air must not award a stunt.

### Task 3: Stunt tracker

**Files:**
- Create: `js/stunts.js`
- Test: `tests/stunts.test.js`

**Interfaces:**
- Produces:
  - `STUNTS = { BIG_AIR: 5, HUGE_AIR: 10, FLIP: 20, BARREL_ROLL: 20, SPIN: 15, RING: 10 }`
  - `createStuntTracker()` → `{ update(frame): StuntEvent | null, reset() }`
    - `frame = { dt, wheelsDown: number, upY: number, pitch: number, roll: number, yaw: number }`. Angles are radians turned this frame around the car's right (x), forward (z) and up (y) axes.
    - `StuntEvent = { names: string[], coins: number, oops: boolean }`. Display names: `'BIG AIR'`, `'HUGE AIR'`, `'FLIP'`, `'BARREL ROLL'`, `'360 SPIN'`, `'RING OF FIRE'`.
  - `throughHoop(prev: {x,y,z}, cur: {x,y,z}, hoop: { x, y, z, radius })` → boolean. The hoop plane is z = hoop.z. True when the segment crosses it at a point within `radius` of (hoop.x, hoop.y).
  - `ringEvent()` → `{ names: ['RING OF FIRE'], coins: 10, oops: false }`. The city calls it when `throughHoop` is true and the tracker reports `airborne`.
  - The tracker exposes `get airborne()`.

- [ ] **Step 1: Write the failing tests** (a helper `fly(tracker, seconds, { pitchRate = 0, rollRate = 0, yawRate = 0 })` feeds 60 Hz frames with `wheelsDown: 0`, then `land(tracker, upY = 1)` feeds frames with `wheelsDown: 4` and returns the first non-null event within 1.2 s)

    - **puppy:** target `PUPPY_SPOTS[variant % 6]`; title "Biscuit the puppy is lost! Can you find him?"; timer null.

    - Emojis: 🍕 🐶 🔵 🤸.

    - `state`: `'ready' | 'offered' | 'running' | 'failed' | 'cooldown'`;
    - `current` (`missionFor(index)` or null); `timeLeft` (number | null);
    - `offer()` → mission (only from `'ready'`; else null);
    - `accept()` → state `'running'`, `timeLeft = mission.timer`;
    - `decline()` → `'ready'`, same index;
    - `cancel()` → `'ready'`, same index, no reward;
    - `update(dt, { player: {x,z}, stunt?: StuntEvent, inStuntPark?: boolean, trailLeft?: number })` → `{ completed: reward } | { failed: true } | null`:
      - **pizza:** complete within 4 m of the target;
      - **puppy:** complete within 3 m;
      - **coinTrail:** complete when `trailLeft === 0`;
      - **stunt:** complete when `inStuntPark` and the stunt has a name matching the goal ('HUGE AIR' counts for 'BIG AIR');
      - timer reaching 0 → `'failed'`;
      - completed → index + 1, state `'cooldown'` for 5 s, then `'ready'`;
    - `retry()` → `'running'`, same mission, fresh timer;
    - `near(player)` → metres to the target (`Infinity` if none), for the puppy woofs and the arrow.
