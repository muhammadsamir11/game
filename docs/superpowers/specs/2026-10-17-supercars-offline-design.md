# Brick Racers — Supercars + Install & Offline — Design Spec

Date: 2026-10-17
Builds on: the base game, figure builder, more parts and mini city 3a/3b specs.

## Purpose
- **Murad (8, iPad) loves supercars:** the design, the brand and the speed. He gets six real-brand supercars to build step by step, new supercar bricks for his own builds, brand badges, and the fastest cars in the game.
- **His parent wants the game installable and playable offline,** in Chrome (desktop and Android) and Safari (iPad / iPhone).

## Decisions (from the user)
- Real brand names: Lamborghini, Ferrari, Bugatti, McLaren.
- The six models (the designer proposed them, the user approved): Lamborghini Aventador, Lamborghini Huracán, Ferrari SF90 Stradale, Ferrari LaFerrari, Bugatti Chiron, McLaren P1.
- Install + offline must work in Chrome and Safari.
- Build it "the same way as before": spec → plan → build natively → one review at the end.

## Constraints
- **Logos:** each brand's badge is a look-alike of its real emblem, drawn in code on a canvas (`js/badgeArt.js`; nothing is downloaded): Lamborghini's gold raging bull on a black shield, Ferrari's black prancing horse on a yellow shield with the green-white-red stripe and S F, Bugatti's red EB oval with its white ring of pearls, and the McLaren wordmark with the papaya speedmark. Build cards and name plates use each brand's colours and lettering. This is a private family game. If it's ever shared publicly or sold, the brand names and emblems must be swapped out.
- **Same stack as before:**
  - Three.js 0.170 + cannon-es 0.20, ES modules, no build step at run time, `node:test`;
  - pure modules stay free of three and the DOM;
  - the server stays `node server.js`.
- **Kid-safe** and touch-first, as before.

## Part 1 — Install & offline
- **No internet at run time:**
  - three (incl. `examples/jsm` addons), cannon-es and the Fredoka font are copied into the repo under `vendor/` and `fonts/`, from npm packages (`three@0.170.0`, `cannon-es@0.20.0`, `@fontsource/fredoka`) by a script, and committed;
  - the import map and CSS point at these local copies;
  - nothing in `index.html` or `css/` refers to another host.
- **Icons:**
  - PNG icons 192 and 512, a 512 maskable icon, and a 180 apple-touch icon, generated by a node script (a red brick racer on the sky blue);
  - the manifest lists them, plus `id`, `scope`, `start_url`, `display: fullscreen`, landscape, and colours.
- **Service worker** (`sw.js`):
  - on install it precaches every game file from `sw-files.js` (a generated list plus a content hash), and serves cache-first;
  - a new hash means a new cache name: the old cache is deleted on activate, and the new version is used from the next launch;
  - a test fails if the list or hash doesn't match the files on disk, so it can't go stale.
- **Install button:**
  - on the home screen, a small "⬇ Install" button appears when the browser offers install (Chrome's `beforeinstallprompt`);
  - on iPad / iPhone Safari (not yet installed), a one-time tip: "Tap Share, then Add to Home Screen";
  - neither shows inside the installed app.
- **Saves:** cars, figures, coins and garage spots already live in localStorage, so they work offline.

## Part 2 — Supercars

**New colour:** `lime` (Huracán green).

**New tray tab "🏎 Supercar":**

| Part | Size (w × d × h) | What it is |
|---|---|---|
| Supercar Nose | 4×2×2 | low wedge |
| Air Scoop | 1×2×2 | side intake |
| Racing Wing | 4×1×4 | tall rear wing; counts as a spoiler |
| Scissor Door | 1×2×3 | shown swung up |
| V12 Engine | 2×2×2 | chrome; counts as the car's engine |
| Super Wheel | wheel, radius 0.38 | low-profile tyre, chrome rim |
| Badge | 2×1×1 | brand shield facing forward |
| Name Plate | 4×1×1 | brand name facing backward |

**Brands** (`js/brands.js`):
- Lamborghini (gold on black shield), Ferrari (black on yellow shield), Bugatti (white on red oval), McLaren (white on papaya).
- `${HERO_NAME} Motors` (yellow on blue star): his own brand and the default for free building.
- A badge or name plate brick carries `badge: '<brand key>'`, like a passenger seat carries `rider`.
- In free building, placing one asks "Which badge?" (tiles of badges), and tapping it again changes it.

**Speed:**
- Every engine part has `power` (Engine 1, V12 2). Engines count by power, still capped at 3.
- Each V12 (up to 2) adds +2.5 m/s top speed.
- So a supercar with one V12 tops out around 19 m/s, a Bugatti with two V12s hits the 24 m/s cap, and old models stay at 14–20.

**The six models:**
- All are built on the usual chassis with four Super Wheels, a V12, a seat, doors, a nose with a badge, a wing and a name plate. They differ in colour and details.
- The Bugatti carries two V12s, so it's the fastest.
- Each model has `brand` and `realTopSpeed` (km/h): Aventador 350, Huracán 325, SF90 340, LaFerrari 350, Chiron 420, McLaren P1 350.
- The build chooser card shows the badge and "🏁 350 km/h", like a trading card.

## Testing
- **Automated:**
  - PWA: no external URLs in `index.html` / CSS; the vendor files exist; the manifest has icons that exist; `sw-files.js` matches the files on disk and their hash.
  - Bricks: valid-brick rules for `badge`; the new parts are in the tray; `lime` exists.
  - Stats: power counts, V12 bonus, the cap.
  - Models: every step can be placed in order; race-ready; uses the new parts; brands and real speeds; every supercar beats every old model's top speed; the Bugatti is fastest.
- **In the browser:**
  - The installed app works with the network off: Chrome install; reload offline; on Safari, Add to Home Screen opens full-screen.
  - Each supercar builds step by step; the badges and name plates read well; races and drives in the city; free build with the badge picker; no console errors.

## Out of scope
Engine-sound variety per brand, a speedometer, and the 3c shop.
